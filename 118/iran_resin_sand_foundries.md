# ریخته‌گری‌ها و کارگاه‌های ایران با سابقه قطعی استفاده از ماسه رزینی

**تاریخ گردآوری:** 2026-10-07

**معیار ورود به فهرست:**  
فقط مجموعه‌هایی وارد فهرست اصلی شده‌اند که شواهد عمومی مشخصی از استفاده از یکی از فرآیندهای **ماسه چراغی، Furan / No-Bake، Hot Box، Cold Box یا سایر سیستم‌های ماسه رزینی** داشته باشند. صرف عبارت «ریخته‌گری ماسه‌ای» یا استفاده از ماسه تر، CO₂ یا سیلیکات سدیم به‌تنهایی برای ورود به فهرست کافی نبوده است.

**معنی فیلد «دامنه استفاده از رزین»:**

- **قالب اصلی + ماهیچه:** شواهد استفاده از ماسه رزینی در خود قالب‌گیری یا هر دو بخش وجود دارد.
- **ماهیچه رزینی:** استفاده از Hot Box / Cold Box یا فرآیند مشابه در ماهیچه‌سازی مستند است، ولی رزینی بودن قالب اصلی قطعی نیست.
- **قالب کامل رزینی / Furan No-Bake:** استفاده از سیستم فوران یا No-Bake برای قالب اصلی مستند است.
- **نامشخص:** استفاده از ماسه رزینی قطعی است، ولی محل دقیق استفاده در خط تولید به‌طور کامل مشخص نشده است.

**معنی امتیاز:**  
امتیاز، کیفیت محصول یا رتبه تجاری شرکت نیست؛ فقط میزان اطمینان به **وجود واقعی فرآیند ماسه رزینی** و ارتباط آن با عملیات ریخته‌گری مجموعه را نشان می‌دهد.

آیا چدن خاکستری، داکتیل، فولاد کربنی، فولاد آلیاژی، استنلس یا آلومینیوم را پوشش می‌دهید؟

**تیراژ:**  
آیا سفارش تک‌قطعه، نمونه‌سازی یا تیراژ پایین قبول می‌کنید؟

**کیفیت سطح و تلرانس:**  
برای قطعه موردنظر چه Surface Finish و چه Dimensional Tolerance قابل تضمین است؟

**بازیابی ماسه:**  
آیا سیستم Sand Reclamation برای ماسه رزینی دارید؟

**کنترل کیفیت:**  
آیا آنالیز ذوب، تست مکانیکی، UT، MT، PT، RT یا سایر آزمون‌های NDT در داخل مجموعه یا از طریق پیمانکار انجام می‌شود؟
